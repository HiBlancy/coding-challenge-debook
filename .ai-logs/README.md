# .ai-logs

Esta carpeta recoge el registro de uso de IA durante la prueba técnica de Debook.

- `prompts.jsonl` — prompts enviados en Claude Code (generado automáticamente por hooks).
- `session-*.jsonl` / `session-*.md` — transcripciones completas de cada sesión de Claude Code.
- `agent-log.md` — log mantenido por otros agentes (Codex, Cursor, ...) según `AGENTS.md`.

**No edites ni borres el contenido de esta carpeta.** Debe incluirse en los commits de tu entrega.
